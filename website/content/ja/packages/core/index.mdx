`@pera1/core` は pera1 のルーター本体です。ルート定義の正規化とマッチング、ローダーとアクションの実行、履歴エントリー単位のデータ管理、エンジンとの接続を担当します。React には依存していないため、他の UI フレームワーク向けのバインディングやテスト用の偽エンジンからも同じように使えます。

## インストール [#install]

```package-install
npm i @pera1/core valibot
```

`valibot` は実行時バリデーションに使うピア依存関係です。`@pera1/react` を使うと、コアは自動的にインストールされます。

## エクスポートの入口 [#entry-points]

パッケージには 3 つのエントリーポイントがあります。通常はルートの `@pera1/core` だけを使えば十分です。

| インポート | 内容 |
| --- | --- |
| `@pera1/core` | ルーター、マッチング、ローダー、アクション、エンジン、エラー、型 |
| `@pera1/core/core` | ルーティングの中核 API (`createRouter`、`matchRoutes` など) |
| `@pera1/core/engines` | エンジンのインターフェースと `NavigationApiEngine` |

## 設計上の約束 [#principles]

- **同期の `init`**: エンジンの初期化は同期です。初期描画に必要な情報はその場で返し、非同期のデータ取得は `NinjaPromise` に包んでストアへ登録します。
- **参照の安定性**: ルーターのスナップショットは参照が安定しており、変化するのは `currentEntry` だけです。購読側はセレクターで必要な部分を取り出します。
- **履歴エントリー単位のキャッシュ**: データは履歴エントリー ID ごとに保持され、破棄されたエントリーのデータは自動で削除されます。
- **失敗はデータとして扱う**: ローダーやアクションの例外は `NinjaPromise` の `rejected` として保持し、表示の判断は UI 側に委ねます。
