---
title: ガイド
description: "実装したい機能から、読むべきガイドを引ける索引です。"
---

ガイドは、実装したいことが決まっているときに該当ページだけを開く参照部です。初めての場合は先に[クイックスタート](/getting-started/quickstart)を済ませておくと、ここでの説明が頭に入りやすくなります。

## 目的から引く [#by-goal]

| やりたいこと | 読むページ |
| --- | --- |
| URL とパラメーターの設計を決めたい | [ルーティング](/guides/routing) |
| 画面に必要なデータを取得したい | [データ取得](/guides/data-loading) |
| 登録・更新・削除を実装したい | [データ更新](/guides/mutations) |
| ボタンや処理の完了後に遷移させたい | [ナビゲーション](/guides/navigation) |
| 取得失敗や 404 を扱いたい | [エラー処理](/guides/error-handling) |
| 画面ごとにバンドルを分割したい | [コード分割](/guides/code-splitting) |
| ルーティングの土台を差し替えたい | [カスタムエンジン](/guides/custom-engines) |
| 型を厳密に付けたい | [TypeScript](/guides/typescript) |

## 共通して出てくる考え方 [#common-ideas]

どのガイドにも、[基本概念](/getting-started/concepts)で説明した 3 つの考え方が繰り返し現れます。ルートは URL の前方一致で親子になること、データは履歴エントリー単位でキャッシュされること、非同期の結果は `NinjaPromise` として届くことです。用語に迷ったら基本概念に戻ってください。
