Guides are reference pages to open when you already know what you want to build. If you are new here, finish the [Quickstart](/getting-started/quickstart) first — it makes everything here easier to follow.

## Shared ideas [#common-ideas]

Every guide repeats the three ideas from [Core concepts](/getting-started/concepts): routes nest by prefix matching, data is cached per history entry, and async results arrive as `NinjaPromise`. If terminology is unclear, go back to core concepts.
